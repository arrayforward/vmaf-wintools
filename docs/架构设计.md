## 2. 模块划分

### 2.1 core/ — 核心库(无 Qt 依赖,可独立复用/测试)

| 文件 | 职责 |
|---|---|
| `frame.h/.cpp` | yuv420p 帧结构、裁剪(`cropFrame`)、缩放(`scaleFrame`,swscale)、RGB 缩略图转换、纯色帧检测 |
| `video_reader.h/.cpp` | `VideoReader` 抽象接口 + `FFmpegReader`(容器解码,sws 统一转 yuv420p 8bit) |
| `yuv_reader.h/.cpp` | `.yuv` 原始文件顺序读取 |
| `frame_aligner.h/.cpp` | 32×32 灰度缩略图、NCC 互相关、绿屏锚点检测、粗对齐、单调序列帧匹配 |
| `vmaf_evaluator.h/.cpp` | libvmaf C API 封装:初始化/模型加载/逐帧送图/分数查询/池化 |
| `pipeline.h/.cpp` | 总控:两遍扫描 → 对齐 → 裁剪 → 送 VMAF → 回调进度/日志/帧结果/汇总 |

### 2.2 gui/ — Qt 界面层

| 文件 | 职责 |
|---|---|
| `main.cpp` | 入口;`--cli` 参数进入命令行模式(复用 core,无窗口) |
| `main_window` | QTabWidget:画质评估 + 视频预处理 |
| `eval_tab` | 评估主界面:文件选择、参数、裁剪联动、进度、日志、曲线联动、导出 |
| `preprocess_tab` | 预处理界面:QProcess 调 ffmpeg 完成绿屏插入 + 转码 |
| `worker` | QThread 包装 Pipeline,回调转 Qt 信号(QueuedConnection 跨线程) |
| `crop_select_widget` | 帧预览 + 拖拽框选,显示/原始坐标双向换算 |
| `vmaf_chart_widget` | 自绘折线图,点击跳转/滚轮缩放/右键平移 |

## 3. 关键设计决策

### 3.1 两遍扫描 vs 单遍
第一遍完整解码两端视频,只提取 32×32 灰度缩略图(4KB/帧)与纯色标记,内存可控(3000 帧 ≈ 12MB),用于离线完成对齐计算;第二遍重新解码,按帧映射送 VMAF。避免随机 seek(不可靠且慢)。

### 3.2 帧对齐算法(详见 主要流程.md)
- 相似度度量:32×32 盒式均值灰度图的 NCC(归一化互相关),对亮度/压缩差异鲁棒
- 单调序列匹配:目标只前进不后退,配合"下一参考帧消歧"处理丢帧
- 绿屏标定:纯色帧(亮度方差≈0)连续段结束点作为锚点,退化为内容匹配兜底

### 3.3 丢帧/冻结与 VMAF 分离
VMAF 本身无法表达"帧丢失",因此只对匹配帧对打分,丢帧率、冻结帧数单独统计输出。

### 3.4 libvmaf 的 Windows 构建
上游 libvmaf 不支持 MSVC(依赖 pthread),采用 **MinGW 编译 DLL + dumpbin/lib 生成 MSVC 导入库** 的方式链接;C API 跨编译器安全(内存分配/释放均在 DLL 内部配对完成)。内置模型因缺 xxd 未编入,随 exe 分发 `models/*.json`。

### 3.5 裁剪坐标系
crop 矩形基于**原始视频像素坐标**,两端各自独立;裁剪后分辨率不一致时失真帧缩放到参考尺寸再送 VMAF(libvmaf 要求两端同尺寸)。默认取中心 1/2 宽高,规避黑边/状态栏/水印。

### 3.6 线程模型
- GUI 线程:只做界面
- EvalWorker(QThread):跑 Pipeline;回调通过信号以队列方式投递到 GUI 线程
- 停止:`std::atomic<bool>` 标志,Pipeline 各循环检查
- 帧回看:评估时缓存每帧 JPEG 级缩略图(480px RGB),3000 帧约 100-200MB,可接受

## 4. 数据结构

```cpp
struct Frame { w,h; y/u/v planes; stride; ptsMs; };      // yuv420p 8bit
struct VideoScan { thumbs[]; solid[]; fps; w,h; };       // 第一遍扫描产物
struct FrameMapping { refToDist[]; refStart; distStart;
                      droppedCount; freezeCount; };       // 对齐产物
struct FrameResult { refIdx; distIdx; dropped; score;
                     rgbRef/rgbDist 缩略图; };            // 逐帧结果
struct Summary { mean; harmonicMean; min; max;
                 matched; dropped; frozen; frames[]; };   // 汇总
```

## 5. 构建与部署

- CMake ≥ 3.20,`find_package(Qt6)` + 手动 find FFmpeg/libvmaf(`FFMPEG_ROOT`、`LIBVMAF_ROOT`)
- `MINGW_BIN` 指定 MinGW bin(libvmaf 运行时 libgcc/libstdc++/libwinpthread 来源)
- POST_BUILD 自动拷贝:FFmpeg DLL、libvmaf DLL、MinGW 运行时、`models/`,并执行 `windeployqt`
- 产物 `build/Release/` 整目录可直接分发
