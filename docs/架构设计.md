## 2. 模块划分

### 2.1 core/ — 核心库(无 Qt 依赖,可独立复用/测试)

| 文件 | 职责 |
|---|---|
| `frame.h/.cpp` | yuv420p 帧结构、裁剪(`cropFrame`)、缩放(`scaleFrame`,swscale)、RGB 缩略图转换 |
| `video_reader.h/.cpp` | `VideoReader` 抽象接口 + `FFmpegReader`(容器解码,sws 统一转 yuv420p 8bit) |
| `yuv_reader.h/.cpp` | `.yuv` 原始文件顺序读取 |
| `frame_aligner.h/.cpp` | QR 帧号精确匹配(参考帧号 → 目标首次出现位置),丢帧/冻结段统计 |
| `marker.h/.cpp` | QR 帧号标记烧录/解码(quirc + qrcodegen),由 QR 外接框反推视频区域 |
| `vmaf_evaluator.h/.cpp` | libvmaf C API 封装:初始化/模型加载/逐帧送图/分数查询/池化 |
| `pipeline.h/.cpp` | 总控:两遍扫描 → 帧号对齐 → 自动裁剪 → 送 VMAF → 回调进度/日志/帧结果/汇总 |

### 2.2 gui/ — Qt 界面层

| 文件 | 职责 |
|---|---|
| `main.cpp` | 入口;`--cli` 参数进入命令行模式(复用 core,无窗口) |
| `main_window` | QTabWidget:采集 + 画质评估 + 视频预处理 |
| `capture_tab` | 采集界面:QProcess 调 adb 定时截屏,输出递增 PNG 序列 + manifest.csv |
| `eval_tab` | 评估主界面:文件选择、参数、进度、日志、曲线、导出 |
| `preprocess_tab` | 预处理界面:QProcess 调 ffmpeg 转码;调 marker_burn 生成帧号片源 |
| `worker` | QThread 包装 Pipeline,回调转 Qt 信号(QueuedConnection 跨线程) |
| `vmaf_chart_widget` | 自绘折线图,点击跳转/滚轮缩放/右键平移 |

## 3. 关键设计决策

### 3.1 两遍扫描 vs 单遍
第一遍完整解码两端视频,只提取帧号标记(QR 解码),用于离线完成对齐计算;第二遍重新解码,按帧映射送 VMAF。避免随机 seek(不可靠且慢)。

### 3.2 帧对齐(QR 帧号,详见 帧号标记规范.md)
- 片源逐帧烧录 QR 帧号(marker_burn);第一遍扫描逐帧解码帧号
- 两端识别率均 ≥80% 才继续:参考帧按帧号查目标侧首次出现位置,精确匹配
- 识别率不足直接报错,提示用 marker_burn 生成片源(不再有绿屏/NCC 回退)

### 3.3 丢帧/冻结与 VMAF 分离
VMAF 本身无法表达"帧丢失",因此只对匹配帧对打分;丢帧数、冻结段数、最长冻结由帧号映射单独统计输出。

### 3.4 libvmaf 的 Windows 构建
上游 libvmaf 不支持 MSVC(依赖 pthread),采用 **MinGW 编译 DLL + dumpbin/lib 生成 MSVC 导入库** 的方式链接;C API 跨编译器安全(内存分配/释放均在 DLL 内部配对完成)。内置模型因缺 xxd 未编入,随 exe 分发 `models/*.json`。

### 3.5 自动裁剪
裁剪不再需要手动框选:帧号对齐成功时,由首个 QR 标记的实测外接框反推各端视频区域(片源端为原始画面,采集端可能是缩放/信箱化画面);反推失败则用全帧。裁剪后分辨率不一致时失真帧缩放到参考尺寸再送 VMAF(libvmaf 要求两端同尺寸)。

### 3.6 线程模型
- GUI 线程:只做界面
- EvalWorker(QThread):跑 Pipeline;回调通过信号以队列方式投递到 GUI 线程
- 停止:`std::atomic<bool>` 标志,Pipeline 各循环检查

## 4. 数据结构

```cpp
struct Frame { w,h; y/u/v planes; stride; ptsMs; };      // yuv420p 8bit
struct VideoScan { markerIndex[]; markerCount;
                   markerQrX/Y/Size; fps; w,h; };         // 第一遍扫描产物
struct FrameMapping { refToDist[]; droppedCount; freezeCount;
                      freezeSegments; freezeMaxLen; };    // 对齐产物
struct FrameResult { refIdx; distIdx; dropped; score;
                     rgbRef/rgbDist 缩略图; };            // 逐帧结果
struct Summary { mean; harmonicMean; min; max;
                 matched; dropped; frozen; markerUnrecognized;
                 markerCoverage; freezeSegments; freezeMaxLen;
                 frames[]; };                             // 汇总
```

## 5. 构建与部署

- CMake ≥ 3.20,`find_package(Qt6)` + 手动 find FFmpeg/libvmaf(`FFMPEG_ROOT`、`LIBVMAF_ROOT`)
- `MINGW_BIN` 指定 MinGW bin(libvmaf 运行时 libgcc/libstdc++/libwinpthread 来源)
- POST_BUILD 自动拷贝:FFmpeg DLL、libvmaf DLL、MinGW 运行时、`models/`,并执行 `windeployqt`
- 产物 `build/Release/` 整目录可直接分发
